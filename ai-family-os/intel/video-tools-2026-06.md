## The technique (the repeatable method we mimic — then beat)
Every top 2026 faceless tutorial is the same loop. The differentiator is **story + consistent
characters**, not the tool. Our version:
1. **Find what works** — analyze winning videos (NotebookLM on transcripts; topic scores). Study patterns; don't copy.
2. **Script** — scene-by-scene master prompt → hook (first 3s) → value → CTA. Our hosts write in character.
3. **Characters** — lock a reference per family member (Seedance / OpenArt) so they're the same in every scene.
4. **Visuals** — stills (GPT Image 2 / Leonardo / OpenArt) → image-to-video (Wan / Kling / Seedance / Veo).
5. **Voice** — our Voice Lab (Kokoro / IndexTTS-2 / ElevenLabs), not default robotic TTS.
6. **Assemble** — captions + music + B-roll (Descript / CapCut); Soundtrack Director owns the score.
7. **Publish** — long on YouTube; cut to Shorts/Reels/TikTok; direct or via Zapier/n8n.
