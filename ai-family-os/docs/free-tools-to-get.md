# Free Tools to Go Get — the shopping list

Free tools I recommend we grab to level up — beyond the open-source agent stack
(`docs/agent-stack-catalog.md`). Grouped by the gap they fill. **Verify the free tier before
relying** (they change monthly). Once we actually use one, it gets a real entry in the Tool Lab.

## 🎨 Images & character consistency (Nova's pick)
| Tool | Why it helps | Free access |
|---|---|---|
| **Leonardo.ai** | Character reference + style presets; great for a consistent cast | Free daily credits |
| **Krea** | Real-time image + upscaling, clean UI | Free tier |
| **Flux (open weights)** | Top open image model — run free via Hugging Face / local | Open / HF Spaces |
| **ComfyUI** | Node-based pipeline — lock a repeatable character workflow | Open-source, local |
| **Photopea** | Free Photoshop in the browser — thumbnails, touch-ups | Free |

## 🎵 Music & audio (Soundtrack Director's pick — we need "good audio")
| Tool | Why | Free access |
|---|---|---|
| **Suno / Udio** | Generate original background scores per episode mood | Free tier (credits) |
| **YouTube Audio Library** | Cleared music + SFX, zero copyright risk | Free |
| **Pixabay Music / Freesound** | Royalty-free beds + SFX (check each license) | Free |
| **Whisper (open)** | Transcription for captions/subtitles, runs local | Open-source |

## 🎬 Footage & stock (free B-roll for the Forge)
- **Pexels · Pixabay · Unsplash** — free stock video + images (cover the claim, avoid "AI slop" look).

## 🧠 Local models / delegation (free workers — sidesteps the spend cap)
- **Ollama** — run open models (Llama, Qwen, DeepSeek, GLM) locally, free, for the volume 90%.
- **OpenRouter free tier** — try many models behind one API key for routing experiments.
  > These are the honest answer to "delegate without spend": a local model does the repetitive
  > drafting for free; the paid frontier is saved for the hard 10%.

## 📊 Distribution & analytics (we already have Postiz)
- Native platform analytics (YouTube Studio, Meta, TikTok) — free; feed numbers back to Atlas/Sage.
- **Plausible/Umami (self-host)** — privacy-friendly site analytics for the brand site, free.

## How to "go get" them (the honest process)
1. I can't sign up for accounts or install local apps from this sandbox (no creds, no arbitrary
   installs). **You create the account / install**, or wire the API key into n8n.
2. Tell me which you grabbed (or drop the API key into n8n / env) → I wire it into the pipeline
   and add a real Tool Lab entry after we test it.
3. Re-verify free tiers quarterly (`skills/genesis-grid/references/free-tool-stack.md`).
