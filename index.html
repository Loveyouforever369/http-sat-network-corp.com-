// Under the hood

Built to go live

Prometheus runs fully in demo mode out of the box — every lesson, sandbox and game works with no setup. Each premium integration is wired to a single config switch, so you can take it live on Vercel whenever you're ready.

🎬 HeyGen Avatars

The lesson player auto-swaps the animated avatar for a real HeyGen video. Map module → video URL in CONFIG.heygen.videos, or wire /api/heygen from api-reference/heygen.ts.

🧠 Claude & GPT Sandbox

The Prompt Sandbox calls CONFIG.sandbox.endpoint. Deploy api-reference/sandbox.ts as a serverless route holding your Anthropic/OpenAI keys — never in the browser.

💳 Stripe Payments

The static-friendly path: create Stripe Payment Links and drop them in CONFIG.stripe.paymentLinks. Buttons go live instantly — no backend required.

🗄️ Supabase + Drizzle

Progress is saved in localStorage using the exact shape of schema.sql (users, modules, lessons, progress, scores) — so promoting to Postgres + Drizzle is a drop-in.

🚀 Deploy to Vercel

This build is zero-config static. From the repo root:

Terminalcd prometheus && vercel deploy --prod

A vercel.json is included. When you're ready to test live HeyGen / Claude / Stripe, that's the moment to add your API keys to the config and serverless routes.
